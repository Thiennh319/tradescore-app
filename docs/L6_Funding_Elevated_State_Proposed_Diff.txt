MỤC 1 — TRACE GAP PHÍA ÂM (ĐỐI XỨNG?)
================================================================================

Điều kiện hiện tại phía âm:
  SHORT_EUPHORIA_FADING : current < -0.005 && velocity > 0  (strict)
  SHORT_SQUEEZE_BUILDING: current < -0.005 && velocity < 0  (strict)
  NEUTRAL (rõ)          : |current| ≤ 0.005 && |velocity| ≤ 0.002

Dải current ∈ [-0.01, -0.005) (tức -0.01 ≤ current < -0.005):

| current  | velocity | Kết quả hiện tại              | Gap?        |
|----------|----------|------------------------------|-------------|
| -0.008   | > 0      | SHORT_EUPHORIA_FADING        | Không       |
| -0.008   | < 0      | SHORT_SQUEEZE_BUILDING       | Không       |
| -0.008   | = 0      | NEUTRAL fallback             | Có          |
| -0.005   | = 0      | NEUTRAL (rõ, |current|≤0.005)| Không       |
| -0.012   | = 0      | NEUTRAL fallback             | Có (ngoài dải đề xuất) |

Kết luận mục 1:
  - Gap phía âm HẸP HƠN NHIỀU so với phía dương.
  - Phía dương: velocity ≥ 0 → toàn dải (0.005, 0.01] (đứng yên + tăng).
  - Phía âm:   chỉ velocity = 0 chính xác trong [-0.01, -0.005).
  - velocity < 0 → đã có SHORT_SQUEEZE; velocity > 0 → đã có SHORT_EUPHORIA.

Đề xuất state đối xứng (optional, cùng PR hoặc phase 2):
  Tên: SHORT_FUNDING_ELEVATED
  Điều kiện: current >= -0.01 && current < -0.005 && velocity === 0
  Raw: LONG = 1.5, SHORT = 0.5
  Đặt SAU SHORT_SQUEEZE, TRƯỚC fallback
  Ưu tiên: thấp — ít gặp thực tế; có thể bỏ qua ở phase 1.
