2. RuleAuditPopulateInput (SAU 05A)
================================================================================

export interface RuleAuditEmaPopulateSource {
  h1: RuleAuditEmaTimeframe;
  h4: RuleAuditEmaTimeframe;
  alignment: string;
  pullback: boolean;
}

export interface RuleAuditPopulateInput {
  ema: RuleAuditEmaPopulateSource;
}

Nguồn h1/h4 dùng type RuleAuditEmaTimeframe từ schema — khớp EMAAnalysisV3
(ema20, ema50, ema200, slope20/50, priceVs*, priceAbove*).

alignment / pullback: caller truyền giá trị đã có (vd. từ L1 khi wire scan).
Populate không derive từ timeframe fields.

================================================================================
3. MAP EMA — CHI TIẾT
================================================================================

populateEmaTimeframe(target, source) — 10 field / TF:

  ema20, ema50, ema200
  slope20, slope50
  priceVsEma20Pct, priceVsEma50Pct
  priceAboveEma20, priceAboveEma50

populateEma(snapshot, ema):

  snapshot.ema.h1  ← ema.h1
  snapshot.ema.h4  ← ema.h4
  snapshot.ema.alignment ← ema.alignment
  snapshot.ema.pullback  ← ema.pullback

populateRuleAuditSnapshot():

  if (input.ema == null) → throw Error('input.ema is required')
  else populateEma(snapshot, input.ema)

Các nhóm snapshot khác (rsi, macd, …): giữ nguyên skeleton từ builder.
