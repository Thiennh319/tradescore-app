## Bước 6 — Protection Layer (xuyên suốt)

Chạy **mỗi scan**, song song hoặc ngay sau Bước 0; kết quả dùng làm **input phụ** — không quyết định Visibility độc lập.

| | Chi tiết |
|---|----------|
| **INPUT** | `RawMarketSnapshot` (Bước 0) **ONLY** — `symbol_klines` (OHLCV + volume; **không** cần `btc_klines`, **không** cần `MarketIntelligenceSnapshot`) |
| **OUTPUT** | `ProtectionSnapshot` (object): |
| | • `stop_hunt_detected` (boolean) |
| | • `stop_hunt_risk` (enum: `LOW` \| `MEDIUM` \| `HIGH`) |
| | • `volatility_risk` (enum: `LOW` \| `NORMAL` \| `HIGH` \| `EXTREME`) |
| | • `volatility_atr_pct` (number, optional — `atr_ratio` × 100 hoặc ATR hiện tại) |
| | • `protection_warnings` (string[]) |

**Consumer:**

| Consumer | Field dùng |
|----------|------------|
| Risk Engine (Bước 4) | `stop_hunt_risk`, `volatility_risk` → điều chỉnh `smart_sl_price`, `risk_approved` |
| Position Management (Bước 5) | `stop_hunt_detected`, `volatility_risk` → advisor / trailing |

### Protection Layer — Input Dependency (làm rõ)

Protection Layer gồm **2 sub-engine**, mỗi sub-engine có dependency riêng (không gộp chung một input):

#### 1. Stop Hunt Detector

| | Chi tiết |
|---|----------|
| **INPUT** | `RawMarketSnapshot.symbol_klines` (Bước 0) — **không** cần `MarketIntelligenceSnapshot` |
| **Logic** | Phát hiện liquidity grab / fake breakout từ price action thuần: wick dài bất thường so với range nến, volume spike rồi đảo trong 1–2 nến — chỉ cần OHLCV |
| **Độc lập** | **Độc lập** với Bước 1 → có thể chạy **ngay sau Bước 0**, song song với Bước 1 và Bước 2 |

#### 2. Volatility Risk Engine

| | Chi tiết |
|---|----------|
| **INPUT** | `ATR(14)` trên 4H — tính **trực tiếp** từ `symbol_klines` (Bước 0), **không** qua Market Intelligence |
| **Logic** | So sánh `ATR(14)` hiện tại với `SMA(ATR(14), 50)` |
| **Độc lập** | Cùng lý do Stop Hunt — **không** phụ thuộc Bước 1 |

**Kết luận:** Protection Layer (cả 2 sub-engine) **chỉ** phụ thuộc Bước 0 (`RawMarketSnapshot`), **không** phụ thuộc Bước 1 (`MarketIntelligenceSnapshot`). Việc vẽ Bước 6 **song song** với Bước 1 **và** Bước 2 trong sơ đồ ASCII là **đúng** — ghi rõ lý do này để tránh hiểu nhầm khi implement (Protection không chờ MI xong mới chạy).

---

### Stop Hunt Detector — công thức

Wick ratio (nến đã đóng):

```
wick_upper = (High − max(Open, Close)) / (High − Low)    // wick trên
wick_lower = (min(Open, Close) − Low) / (High − Low)     // wick dưới
wick_ratio = max(wick_upper, wick_lower)
```

**Stop Hunt nghi ngờ** khi **đủ cả 2**:

1. `wick_ratio > 0.7` (wick chiếm hơn 70% range nến)
2. Nến **ngay sau** đó đóng **ngược** hướng wick (ví dụ: wick dưới dài nhưng nến tiếp theo đóng tăng mạnh → xác nhận “quét” rồi bật lại, không phải breakdown thật)

`stop_hunt_detected` = true khi thỏa cả hai điều kiện trên.

**Phân loại `stop_hunt_risk`:**

| Điều kiện | `stop_hunt_risk` |
|-----------|------------------|
| `wick_ratio > 0.85` **và** `volume > volumeMA20 × 1.5` (volumeMA20: SMA 20 nến trước, cùng quy tắc Engine 2) | **HIGH** |
| `wick_ratio > 0.7` (và đã xác nhận nến sau đảo chiều) | **MEDIUM** |
| Không thỏa | **LOW** |

---

### Volatility Risk Engine — công thức

```
atr_ratio = ATR(14)_current / SMA(ATR(14), 50)
```

`ATR(14)`: Wilder trên nến 4H đã đóng (từ `symbol_klines`).

**Phân loại `volatility_risk`:**

| `atr_ratio` | `volatility_risk` |
|-------------|-------------------|
| `> 2.0` | **EXTREME** |
| `1.5 – 2.0` | **HIGH** |
| `1.0 – 1.5` | **NORMAL** |
| `< 1.0` | **LOW** |
