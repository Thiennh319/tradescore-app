PHẦN 4 — EVIDENCE MAPPING REPORT
================================================================================

| Nguồn Rule Engine        | Evidence Kind              | originRuleId   | sourceModule |
|--------------------------|----------------------------|----------------|--------------|
| hardBlocks[i]            | RULE_ENGINE_RETURNED_BLOCK | prefix map*    | RuleEngine   |
| groupBlocks[i]           | GROUP_BLOCK_ACTIVE         | HB-MED-01*     | RuleEngine   |
| adxGateBlocked=true      | ADX_BELOW_THRESHOLD        | HB-CRIT-01     | RuleEngine   |
| tradePlanValid=false     | TRADE_PLAN_INVALID         | null           | RuleEngine   |
| blockReasons[i]          | BLOCK_REASONS_PRESENT      | HB-LOW-01*     | RuleEngine   |

* prefix map (RuleBook §6 — không tạo ID mới):
  L3 MACD              → HB-HIGH-05
  CVD deeply negative… → HB-HIGH-01
  CVD +…> +2M          → HB-HIGH-02
  Funding …            → HB-HIGH-04
  BTC quá rủi ro       → HB-CRIT-03
  BTC ≤ -2% / ≥ +2%    → HB-HIGH-03
  L9 Phiên xấu         → HB-MED-02
  L10 / Tâm lý         → HB-MED-03
  Nhóm A/B/C           → HB-MED-01
  L5a …                → HB-LOW-01

THIẾU Rule ID (originRuleId = null — chờ phê duyệt nếu cần taxonomy):
  tradePlanValid=false — RuleBook không có HB-* riêng cho invalid plan geometry.
  hardBlocks message không khớp prefix map — null (passthrough vẫn có evidence).

Evidence fields: kind, description, rawValue, originRuleId, sourceModule, timestamp
  timestamp: marketSnapshot.timestamp hoặc placeholder 1970-01-01T00:00:00.000Z
