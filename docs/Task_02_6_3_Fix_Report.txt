PHẦN 3 — STABLE ACTION IDs
================================================================================

Trước (removed):
  ESM-ACT-{ActionType}-{From}-{To}

Sau (policy table):

| actionId          | Transition        | actionType     |
|-------------------|-------------------|----------------|
| ENTRY-ACTION-001  | IDLE → WATCH      | NO_ACTION      |
| ENTRY-ACTION-002  | WATCH → READY     | PREPARE_ENTRY  |
| ENTRY-ACTION-003  | READY → ENTRY     | CONFIRM_ENTRY  |
| ENTRY-ACTION-004  | ENTRY → ACTIVE    | OPEN_POSITION  |
| ENTRY-ACTION-005  | ACTIVE → EXIT     | PREPARE_EXIT   |
| ENTRY-ACTION-006  | EXIT → IDLE       | RESET_STATE    |

Deterministic — không UUID, timestamp, random, enum name dependency.
