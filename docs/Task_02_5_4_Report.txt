PHẦN 5 — RESOLUTION RULES
================================================================================

Catalog priority (từ TRIGGER_TYPE_CATALOG):

| Trigger      | Priority |
|--------------|----------|
| HardBlock    | 100      |
| Recovery     | 70       |
| Unlock       | 70       |
| Confirmation | 60       |
| Noise        | 50       |

RULE:
  - Khác priority → RESOLVED, winner = trigger priority cao nhất
  - Cùng priority → UNRESOLVED, winningTrigger=null, suppressedTriggers=[]

Ví dụ:
  HardBlock vs Confirmation → RESOLVED (HardBlock)
  HardBlock vs Noise        → RESOLVED (HardBlock)
  Confirmation vs Noise     → RESOLVED (Confirmation)
  Recovery vs Unlock        → UNRESOLVED
