Orchestrator đặc tính:
  • Synchronous — không Promise / async
  • Deterministic — không UUID / random / timestamp trong orchestration
  • Không mutate input context
  • Không swallow exception — throw khi context invalid; downstream errors propagate
  • Không retry / timeout / scheduler / EventBus
