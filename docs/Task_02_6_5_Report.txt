interface RuntimeDispatcherContext {
  actionRuntimeResult: ActionRuntimeResult
  scanId?: string
}

interface RuntimeDispatcherResult {
  actionRuntimeResult    // passthrough
  dispatchPlan
  dispatchCount
  halted
  message
  context
}

interface RuntimeDispatchItem {
  dispatchId
  actionId
  executionOrder
  dispatchStatus
  metadata               // actionType, fromState, toState, reason
}

enum RuntimeDispatchStatus {
  QUEUED
  SKIPPED
}

Không có RUNNING / SUCCESS / FAILED / CANCELLED / TIMEOUT.

dispatchId format: DISPATCH-001, DISPATCH-002, ... (deterministic)

PHẦN 3 — DISPATCH FLOW
================================================================================

  validateRuntimeDispatcherContext()
        ↓
  buildDispatchPlan()
        ↓
  validateRuntimeDispatcherResult()
        ↓
  return RuntimeDispatcherResult

buildRuntimeDispatcherResult(context) — entry point.

Rules:
  • Mỗi RuntimeAction → đúng 1 RuntimeDispatchItem
  • RuntimeAction.status SKIPPED → dispatchStatus SKIPPED
  • Ngược lại → dispatchStatus QUEUED
  • dispatchCount = dispatchPlan.length
  • Không reorder / scheduler / queue implementation
