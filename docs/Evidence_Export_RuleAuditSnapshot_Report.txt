4. CHI TIẾT TỪNG NHÓM
================================================================================

── EMA (RuleAuditEmaInput) ──────────────────────────────────────────────────

  h1, h4: RuleAuditEmaTimeframe
    ema20, ema50, ema200
    slope20, slope50          → RuleAuditSlope
    priceVsEma20Pct, priceVsEma50Pct
    priceAboveEma20, priceAboveEma50
  alignment: string           → schema tự do (wire sau — enum L1)
  pullback: boolean           → flag pullback EMA

  Map tương lai: EMAAnalysisV3 (indicators.ts) × 2 TF + L1 derive flags

── RSI (RuleAuditRsiInput) ──────────────────────────────────────────────────

  rsi1h, rsi4h: number
  divergence1h, divergence4h: RuleAuditDivergence (BULLISH|BEARISH|NONE)

  Map: getRSI + detectRSIDivergenceV3

── MACD (RuleAuditMacdInput) ────────────────────────────────────────────────

  h1, h4: RuleAuditMacdTimeframe
    macd, signal, histogram
    isTurningUp, isTurningDown
    crossedZeroRecentlyUp, crossedZeroRecentlyDown

  Map: MACDAnalysisV3

── Bollinger (RuleAuditBollingerInput) ───────────────────────────────────────

  h1, h4: RuleAuditBollingerTimeframe
    percentB, bandwidth, bandwidthSlope, marketMode
    upper, middle, lower (giá band cuối)

  Map: BollingerAnalysisV3 + band prices

── Volume (RuleAuditVolumeInput) ────────────────────────────────────────────

  volumeRatio1h, volumeRatio4h
  lastVolume, avgVolume1h

  Map: getVolumeRatio

── CVD (RuleAuditCvdInput) ──────────────────────────────────────────────────

  value, trend (UP|DOWN|FLAT), slope (up|down|flat)
  divergence, divergenceType, supportive
  cvdMomentum24h, reason

  Map: CVDAnalysis + analyzeCVD + latest CVDPoint

── OI (RuleAuditOiInput) ────────────────────────────────────────────────────

  current, previous, delta
  change1hPct, change4hPct

  Map: AnalysisInputV4.oiChange* + oiEngine

── Funding (RuleAuditFundingInput) ──────────────────────────────────────────

  ratePct, avg8, avg16, velocity, acceleration, state

  Map: FundingMetricsPct + FundingState label

── LongShortRatio (RuleAuditLongShortRatioInput) ───────────────────────────

  topRatio, globalRatio, topHistory[]

  Map: topLongShortRatios history

── BTC Context (RuleAuditBtcContextInput) ───────────────────────────────────

  change24hPct, change1hPct, trend, regimeConfidence

  Map: btc24hChangePct + analysis.smc.trend

── ADX (RuleAuditAdxInput) ──────────────────────────────────────────────────

  Phân tích: adx1h, adx4h, adxAvg, regime, regimeStrength
             isChoppy1h, isChoppy4h, bothChoppy
  Gate:      gateAllowed, gateBlock, gateSeverity
             gateTpMultiplier, gateSlMultiplier, gateMessage

  Map: ADXAnalysis + ADXGateResult (gộp 1 nhóm — tránh 2 key riêng)

── VWAP (RuleAuditVwapInput) ────────────────────────────────────────────────

  vwap, bands (1/2), priceVsVwap, zone, isNearVwap, isPullingBackToVwap
  sessionStart, candleCount
  entryQuality, suggestedEntry, entryReason

  Map: VWAPResult + VWAPEntrySignal

── ATR (RuleAuditAtrInput) ─────────────────────────────────────────────────

  atr1h, atr1hPct

  Map: row.atr1h / computeAtr1hFromKlines

── Structure (RuleAuditStructureInput) ──────────────────────────────────────

  swingPrice, swingTime, slPrice, slSource (STRUCTURE|ATR_FALLBACK)
  bufferPct, distanceFromEntry, candlesBack, lookbackCandles

  Map: StructureSLResult + resolveStructureSlLookback config
