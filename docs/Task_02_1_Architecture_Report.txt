4. DATA CONTRACT
--------------------------------------------------------------------------------

4.1 Input — EntryStateManagerInput
  Mô tả read-only context từ Rule Engine output (§8.1, §9.3).
  Field types cố ý loose (string cho decision) để tránh coupling scaffold → scorer.

4.2 Output — EntryStateSnapshot
  Single source of truth per (symbol, direction) per scan (§9.2).
  Chứa: entryState, previousState, transition, lockStatus, commitScore, …

4.3 Persistence shape — EntryStateRecord
  snapshot + hysteresis counters + config snapshot + lockZoneBounds.

4.4 Audit — EntryStateAuditSection
  Map trực tiếp RuleBook §7.1 + §7.2 cho export package tương lai.
