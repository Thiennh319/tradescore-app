PHẦN 2 — INTEGRATION FLOW
================================================================================

        │
        ▼

        │
        ▼

        │
        ▼
  injectCurrentStateIntoPipeline()   ← harness-only tail re-run
        │
        ▼
  IntegrationHarnessResult

injectCurrentStateIntoPipeline():
  Re-runs state machine → action engine → action runtime → dispatcher → executor
  with context.currentState — without modifying PipelineOrchestrator module.

Harness đặc tính:
  • Synchronous — không Promise / async
  • Deterministic
  • Không mutate input
  • Không swallow exception
  • Không retry / scheduler / timeout / EventBus / execute

PHẦN 3 — CONTEXT & RESULT MODEL
================================================================================

IntegrationHarnessContext:
  signalBoardScan    SignalBoardScanSnapshot
  marketSnapshot     EntryStateMarketSnapshot
  triggerSnapshot    SignalBoardTriggerSnapshot
  currentState       EntryState (state machine — injected)
  scanId             string
  timestamp          ISO8601 string

IntegrationHarnessResult:
  adapterResult      SignalBoardAdapterResult
  pipelineResult     PipelineOrchestratorResult (with injected currentState)
  halted             boolean — mirrors pipelineResult.halted
  message            string
  context            IntegrationHarnessContext (copied passthrough)

PHẦN 4 — VALIDATION
================================================================================

validateIntegrationHarnessContext():
  • delegate validateSignalBoardAdapterContext()
  • currentState must be valid state machine EntryState (isStateMachineEntryState)

validateIntegrationHarnessResult():
  • delegate validateSignalBoardAdapterResult()
  • delegate validatePipelineOrchestratorResult()
  • halted === pipelineResult.halted
  • pipelineResult.stateMachineResult.currentState === context.currentState
  • context.scanId === adapterResult.scanId
