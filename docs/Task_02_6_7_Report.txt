PHẦN 7 — NAMING CLEANUP
================================================================================

Convention xác nhận (không đổi tên public API — chỉ document):

  *Context              — input DTO cho mỗi layer
  *Result               — output DTO (context, halted, message, passthrough, count)
  validate*Context()    — structural + policy guard
  validate*Result()     — post-build integrity
  build*Result()        — orchestration entry
  collect*()            — extract candidates/actions từ upstream
  resolve*()            — policy/state resolution
  build*Id()            — deterministic id (ENTRY-ACTION-NNN, DISPATCH-NNN, EXECUTION-NNN)

Deterministic IDs (không UUID / random / Date.now trong id generation):
  ENTRY-ACTION-001..006  — ACTION_POLICY
  DISPATCH-001..       — RuntimeDispatcher
  EXECUTION-001..      — RuntimeExecutor

Timestamp fields: chỉ passthrough từ marketSnapshot / evidence input — không
dùng để sinh id hay quyết định pipeline.
