1. NÚT EXPORT TRÊN UI — HÀM ĐƯỢC GỌI
================================================================================

    → exportSignalData(rows, 'txt')
    → exportSignalData(rows, 'csv')

Tab V4.1 (SignalBoardV41.tsx):
  handleExport()
    → exportV41SignalReport(rows, quotes)
      → exportSignalDataV41(rows, quotes, 'txt')
      → exportSignalDataV41(rows, quotes, 'csv')

  Không có nút Export.

3. CHUỖI GỌI CSV THỰC TẾ (TAB V4)
================================================================================

SignalBoard.tsx handleExport
  → exportSignalData(rows, 'csv')
    → rows.map(buildExportRow)
    → formatAsCSV(exportRows)
      → header: CSV_COLUMNS.join(',')

File output: tradescore-signal-{timestamp}.csv

================================================================================
4. CHUỖI GỌI CSV THỰC TẾ (TAB V4.1)
================================================================================

SignalBoardV41.tsx handleExport
  → exportV41SignalReport(rows, quotes)
    → exportSignalDataV41(rows, quotes, 'csv')
      → header: CSV_COLUMNS (V41).join(',')

File output: tradescore-v41-signal-{timestamp}.csv

================================================================================
5. SỐ CỘT CSV THỰC TẾ
================================================================================

UI Tab V4:
  Nguồn header: CSV_COLUMNS (exportService.ts)
  Số cột: 80
  Cột đầu: timestamp,symbol,price,priceChange24h,scoreTotal,...

UI Tab V4.1:
  Nguồn header: CSV_COLUMNS (exportServiceV41.ts)
  Số cột: 61

Evidence contract (không qua UI):
  Nguồn header: RULE_AUDIT_EVIDENCE_CSV_COLUMNS (exportService.ts)
  Số cột: 125
  Cột đầu: symbol,ema.h1.ema20,ema.h1.ema50,...

================================================================================
6. SO SÁNH VỚI RULE_AUDIT_EVIDENCE_CSV_COLUMNS (125)
================================================================================

RULE_AUDIT_EVIDENCE_CSV_COLUMNS = symbol (1)
  + RULE_AUDIT_SNAPSHOT_CSV_COLUMNS (120)
  + RULE_AUDIT_EVIDENCE_METADATA_COLUMNS (4)
  = 125 cột

Metadata:
  evidence_version, snapshot_version, rule_version, export_timestamp

================================================================================
7. VÌ SAO FILE CSV UI KHÔNG CÓ 125 CỘT
================================================================================

Nguyên nhân:
  Nút Export trên UI vẫn dùng export legacy (exportSignalData / exportSignalDataV41).
  exportRuleAuditEvidenceCSV đã implement 125 cột nhưng CHƯA được wire vào UI.
  exportRuleAuditEvidenceCSV chỉ được gọi nội bộ trong exportService.ts
    (validateCsvExportAcceptance — acceptance probe).

Hai schema CSV hoàn toàn khác:

  UI V4 (80 cột):
    timestamp, scoreTotal, l1_ema, finalDecision, entry, sl, tp1, ...

  Evidence (125 cột):
    symbol, ema.h1.ema20, rsi.rsi1h, funding.ratePct, evidence_version, ...
