PHẦN 2 — ADAPTER MODEL
================================================================================

Input — SignalBoardAdapterContext:

  signalBoardScan   SignalBoardScanSnapshot (adapter-owned slim contract)
  marketSnapshot    EntryStateMarketSnapshot
  triggerSnapshot   SignalBoardTriggerSnapshot (detector + optional staged outputs)
  scanId            string
  timestamp         ISO8601 string

Output — SignalBoardAdapterResult:

  aggregateContext   TriggerAggregatorContext
  priorityContext    PriorityResolverContext
  conflictContext    ConflictResolverContext
  decisionContext    DecisionEngineContext
  scanId             string
  timestamp          string

SignalBoardScanSnapshot (minimal row mirror — no import signalBoardScan.ts):

  symbol, price, direction, canEnter, hardBlocked
  decisionLabel?, decisionDisplay?

SignalBoardTriggerSnapshot:

  hardBlockResult?, recoveryResult?, unlockResult?,
  confirmationResult?, noiseResult?
  aggregateResult?, priorityResult?, conflictResult?  (optional passthrough)

PHẦN 3 — MAPPING FLOW
================================================================================

  SignalBoardScan snapshot
        │
        ▼
  validateSignalBoardAdapterContext()
        │
        ▼
  buildSignalBoardAdapterResult()     ← field copy only
        │
        ├── aggregateContext  ← detector slots + scanId
        ├── priorityContext   ← aggregateResult shell or staged passthrough
        ├── conflictContext   ← priorityResult shell or staged passthrough
        └── decisionContext   ← conflictResult shell or staged passthrough
        │
        ▼
  aggregateTriggers(aggregateContext)   ← integration orchestrator (Task 02.7.2+)
        │
        ▼
  Pipeline tiếp tục bình thường (resolvePriority → resolveConflicts → …)

Adapter KHÔNG gọi aggregateTriggers, resolvePriority, resolveConflicts,
buildDecisionEngineResult, hay bất kỳ runtime evaluator nào.

Shell placeholders (message: 'signal-board-adapter-mapped') cho phép orchestrator
biết cần thay bằng output thật từ pipeline. Khi triggerSnapshot đã bundle
staged results, adapter passthrough nguyên vẹn.

================================================================================
PHẦN 4 — VALIDATION
================================================================================

validateSignalBoardAdapterContext():
  • scanId — non-empty string
  • timestamp — non-empty string
  • signalBoardScan — required, symbol/price/direction/canEnter/hardBlocked
  • marketSnapshot — required, symbol/markPrice/timestamp
  • symbol consistency — marketSnapshot.symbol === signalBoardScan.symbol
  • triggerSnapshot — required object

validateSignalBoardAdapterResult():
  • scanId + timestamp on result
  • aggregateContext.scanId matches result.scanId
  • priorityContext / conflictContext / decisionContext scanId alignment
  • nested upstream objects present (aggregateResult, priorityResult, conflictResult)

Immutability:
  • copyTriggerSnapshot() — shallow field copy
  • buildSignalBoardAdapterResult() không mutate input context
