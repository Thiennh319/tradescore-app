PHẦN 5 — RUNTIME FLOW
================================================================================

  validateFinalDecisionContext()
        ↓
  collect ELIGIBLE candidates
        ↓
  build FinalDecision (selection rules)
        ↓
  validateFinalDecisionResult()
        ↓
  return FinalDecisionResult

buildFinalDecisionResult(context) — entry point.

Selection order (ưu tiên):
  1. UNRESOLVED present  → Rule 3
  2. multiple ELIGIBLE   → Rule 2
  3. exactly 1 ELIGIBLE  → Rule 1
  4. zero candidates     → Rule 5
  5. all BLOCKED         → Rule 4

================================================================================
PHẦN 6 — SELECTION RULES
================================================================================

| Rule | Điều kiện                    | decisionCount | finalDecision | halted | message                              |
|------|------------------------------|---------------|---------------|--------|--------------------------------------|
| 1    | đúng 1 ELIGIBLE              | 1             | candidate     | false  | Final decision selected.             |
| 2    | >1 ELIGIBLE                  | 0             | null          | true   | Multiple eligible candidates.        |
| 3    | có UNRESOLVED                | 0             | null          | true   | Unresolved decision candidates.      |
| 4    | tất cả BLOCKED               | 0             | null          | false  | All candidates blocked.              |
| 5    | không có candidate           | 0             | null          | false  | No decision candidate.               |
