================================================================================

PositionAdviserHarnessContext:
  adapterResult   PositionAdviserAdapterResult
  scanId          string (must match adapter + integration context)
  timestamp       string (must match adapter + integration context)

PositionAdviserHarnessResult:
  adapterResult         PositionAdviserAdapterResult (passthrough)
  positionAdviserInput  PositionAdviserInput (passthrough summaries)
  scanId                string
  timestamp             string
  halted                boolean (= adapterResult.context.halted)
  message               string
  context               PositionAdviserHarnessContext
