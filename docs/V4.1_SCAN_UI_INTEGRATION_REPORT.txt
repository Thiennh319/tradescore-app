3. LUỒNG SCAN V4.1 (scanV41.ts)
--------------------------------------------------------------------------------

  Input:  symbols: string[]  (default NEAR, SOL, BNB, BTC)

  Mỗi symbol (Promise.allSettled — song song):
    1. fetchRawMarketV41(symbol)
         - fetchKlines từ services/binanceApi.ts
         - interval 4h, limit 250
         - symbol + BTCUSDT song song
         - lọc nến đóng: closeTime < now - 1000ms

    2. runMarketIntelligenceLayer(klines, btcKlines)
         a) Engine 1 → trendStrength, trendDirection
         b) Engine 2 → trendExhaustion, volumeDivergencePts
         c) Engine 3 → reversalProbability, rsi/cvd divergence
         d) buildBTCContext(btcKlines) → btcDirection
         e) resolveAltBtcAlignmentFactor (matrix alt/BTC)
         f) computeMarketConfidence
         g) calculateMarketState → marketState
         - Throw toàn cục → neutral snapshot (Transition)

    3. Visibility
         resolveVisibilityHysteresis(mi, EMPTY_POSITION, 'INACTIVE')
         resolveTradeModeUpgrade(mode, false, marketConfidence)
         ※ marketConfidence tạm thay entry_quality (Bước 3 chưa có)
         ※ previousMode luôn INACTIVE — chưa persist hysteresis

  Output: SignalRowV41[]
    {
      symbol, snapshot, visibilityMode, fetchedAt, error?
    }

  Lỗi 1 symbol:
    - Không crash batch
    - error field + snapshot neutral + visibilityMode INACTIVE
