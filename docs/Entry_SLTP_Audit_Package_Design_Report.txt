--------------------------------------------------------------------------------
SECTION 2 — AI AUDIT INSTRUCTION (tradeScoreAiAuditInstruction.ts)
--------------------------------------------------------------------------------
14 nhiệm vụ AI Auditor:
  1. Đọc Rule Book
  2. Đọc Decision Trace
  3. Đọc Market Evidence
  4. Đọc Actual Result
  5. Không suy diễn ngoài Rule
  6. Tự tính Expected theo Rule Book
  7. So sánh Expected vs Actual
  8. PASS/FAIL từng Layer
  9. FAIL → Rule/Module/Expected/Actual/Root Cause
  10-12. Không đề xuất chiến lược / không tối ưu / không sửa Rule
  13. Chỉ đánh giá app đúng Rule
  14. Sinh Prompt Cursor sửa module
Tái dùng: CÓ — thay "từng Layer L1-L11" → Entry/SL/TP/RR/Quality.

--------------------------------------------------------------------------------
SECTION 3 — AI AUDIT WORKFLOW (tradeScoreAiAuditInstruction.ts)
--------------------------------------------------------------------------------
STEP 1: Validate package (Rule Book, Instruction, Prompt, Template, Evidence)
STEP 2: Đọc Rule Book (SSOT)
STEP 3: Đọc Evidence (không giả định)
STEP 4: Replay từng Layer L1→L11 (Input/Expected/Actual/PASS-FAIL)
STEP 5: Replay Group Score → Decision → Trade Plan → Final Status
STEP 6: Expected == Actual → PASS, else FAIL
STEP 7: FAIL → Module/Function/Rule/Evidence/Root Cause/Cursor Prompt
STEP 8: Không thêm/sửa Rule
Tái dùng: CÓ — STEP 4/5 thu hẹp pipeline Entry→SL→TP→RR.

--------------------------------------------------------------------------------
SECTION 4 — MASTER AUDIT PROMPT (tradeScoreMasterAuditPrompt.ts)
--------------------------------------------------------------------------------
- Mục tiêu: kiểm tra app vs RuleBook
- Nguồn duy nhất: nội dung package
- Quy trình 8 bước: Rule Book → Evidence → Expected (Decision, L1-L11,
  Hard Block, Entry, SL, TP) → Compare → PASS/FAIL
- Ràng buộc: không suy diễn; INSUFFICIENT EVIDENCE nếu thiếu data
Tái dùng: CÓ — đã có Expected Entry/SL/TP; bỏ phần Layer.

--------------------------------------------------------------------------------
SECTION 5 — AI OUTPUT TEMPLATE (tradeScoreAuditOutputTemplate.ts)
--------------------------------------------------------------------------------
- OVERALL RESULT (PASS/FAIL/INSUFFICIENT_EVIDENCE, Confidence, Summary)
- RULE CHECK (Rule Book, Decision Trace, Market Evidence, Actual Result)
- LAYER AUDIT L1-L11 (mỗi layer: PASS/FAIL, Expected, Actual, Reason)
- TRADE PLAN AUDIT (Decision, Direction, Entry, Stop Loss, Take Profit, Hard Block)
- ROOT CAUSE + FIX RECOMMENDATION
Tái dùng: Phần TRADE PLAN AUDIT + ROOT CAUSE;
           thay LAYER AUDIT bằng ENTRY/SL/TP/RR checklist.

#  | Section                      | Nội dung

   |                              | Entry → ADX scale → VWAP → Structure SL
   |                              | → RR check; STEP 5 bỏ Group/Decision
4  | MASTER AUDIT PROMPT          | Clone; Expected chỉ Entry/SL/TP/RR/Quality
5  | AI OUTPUT TEMPLATE           | Bỏ LAYER AUDIT; mở rộng TRADE PLAN AUDIT:
   |                              | Entry, Entry Quality, SL price/source/quality,
   |                              | ATR dist, TP1-3, RR1-3, primary RR,
   |                              | ADX mult, Structure lookback
6  | EXECUTIVE SUMMARY            | Per coin: Symbol, Direction, Entry, SL,
   |                              | TP1-3, Primary RR, Entry Quality, SL Quality,
   |                              | SL Source, Final Entry Status. Không L1-L11.
7  | MARKET EVIDENCE              | Chỉ ATR, VWAP, STRUCTURE, ADX + price,
   |                              | direction. Optional mini EMA20 (ảnh hưởng entry).

   |                              | Expected entry, SL, TP1-3, RR, qualities.

   |                              | "Rule Decision" để tránh nhầm layer scores.)
9  | ACTUAL TRADE PLAN            | App sau full pipeline: resolveTradePlanV3,
   |                              | structureSL, adxGate, vwapSignal
10 | ACTUAL RESULT                | TXT subset: KẾ HOẠCH + STRUCTURE SL + VWAP
   |                              | + ADX GATE + audit fields. Không 10 layer.
11 | BASELINE                     | Checklist module Entry/SL/TP; không scoring
