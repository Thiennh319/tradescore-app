Cấu trúc MTF — không dùng tên phẳng macd1h:

    h1: RuleAuditMacdTimeframe   // 1H

RuleAuditMacdTimeframe (7 field / TF):
  macd, signal, histogram
  isTurningUp, isTurningDown

Khớp MACDAnalysisV3 (indicators.ts) — caller map trực tiếp.

================================================================================
4. ĐOẠN POPULATE MACD
================================================================================

function populateMacdTimeframe(target, source):
  map 7 field 1:1 (macd, signal, histogram, isTurning*, crossedZero*)

function populateMacd(snapshot, macd):
  populateMacdTimeframe(snapshot.macd.h1, macd.h1)
  populateMacdTimeframe(snapshot.macd.h4, macd.h4)

populateRuleAuditSnapshot:
  if (input.macd == null) throw 'input.macd is required'
  populateMacd(snapshot, input.macd)
