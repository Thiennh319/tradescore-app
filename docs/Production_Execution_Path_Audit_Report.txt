EXECUTIVE SUMMARY
-----------------
Production scoring for Signal Board is driven by:

  scanSignalSymbol (signalBoardScan.ts)
    → scoreAnalysisV4 (scorerV4.ts)
    → getEMAAnalysisV3 / buildCVDPointsFromKlines / hardBlocks[] + ADX overlay

V4.1 runs a fully separate parallel stack (v41/indicators, momentumEngine1H,
separate CVD models). Default UI tab is "unified" (App.tsx).

Legacy code still executes on every scan via computeFullAnalysisBundle
(runFullAnalysis / makeDecision). Unified tab has a wiring gap: buildV41Row
omits momentum before unifiedSignalEngine gate.
