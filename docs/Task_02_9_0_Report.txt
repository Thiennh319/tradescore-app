PHẦN 1 — ARCHITECTURE
================================================================================

Luồng mapping chính thức (chỉ qua bridge):

  Production FinalEntryStatus (types/scoring.ts)
        │
        ▼ mapFinalEntryStatusToEntryState()
  RuleBook EntryState (enums.ts — 4 states)
        │
        ▼ mapEntryStateToStateMachine()
  StateMachine EntryState (stateMachineTypes.ts — 8 states)

Composite: mapFinalEntryStatusToStateMachine() = hai bước trên.

Reverse: mapStateMachineToEntryState() — chỉ 4 state trùng tên (READY/WATCH/
LOCKED/BLOCKED). IDLE, ENTRY, ACTIVE, EXIT → NOT_YET_MAPPED (throw).

Không có reverse FinalEntryStatus từ RuleBook — documented as NOT_YET_MAPPED
vì many-to-one (3 block types → BLOCKED) và LOCKED cần lock-zone context.

Freeze: Entry State Mapping Bridge là THE ONLY OFFICIAL MAPPING LAYER.
UI Integration MUST use EntryStateMapping — no direct enum comparison outside.

PHẦN 4 — MAPPING TABLE (CANONICAL)
================================================================================

A. FinalEntryStatus → RuleBook EntryState
-------------------------------------------

  FinalEntryStatus     RuleBook EntryState   Evidence
  ----------------     -----------------   --------
  ENTRY_VALID          READY               entryStateMetadata.ts READY.businessMeaning:
                                           "Tương đương FinalEntryStatus.ENTRY_VALID (§1.1)"

  WAIT_ENTRY           WATCH               finalEntryStatus.ts: WAIT_ENTRY when !tradePlanValid;
                                           entryStateMetadata.ts WATCH.whenToUse: "plan/R:R chưa sẵn"

  SCORE_BLOCKED        BLOCKED             entryStateMetadata.ts BLOCKED.businessMeaning:
                                           "Map HARD/GROUP/SCORE_BLOCKED"

  GROUP_BLOCKED        BLOCKED             (same evidence as SCORE_BLOCKED)

  HARD_BLOCKED         BLOCKED             (same evidence as SCORE_BLOCKED)

  NOTE: No FinalEntryStatus maps to LOCKED — LOCKED requires Entry Lock Zone
  context (entryStateMetadata.ts LOCKED.businessMeaning). NOT derivable from
  FinalEntryStatus alone.

B. RuleBook EntryState → StateMachine EntryState
-------------------------------------------------

  RuleBook EntryState   StateMachine EntryState   Evidence
  -------------------   -----------------------   --------
  READY                 READY                     Identical string value (enums.ts + stateMachineTypes.ts)
  WATCH                 WATCH                     Identical string value
  LOCKED                LOCKED                    Identical string value
  BLOCKED               BLOCKED                   Identical string value

C. StateMachine EntryState → RuleBook EntryState (reverse)
-----------------------------------------------------------

  StateMachine EntryState   RuleBook EntryState   Status
  -----------------------   -----------------   ------
  READY                     READY                 MAPPED
  WATCH                     WATCH                 MAPPED
  LOCKED                    LOCKED                MAPPED
  BLOCKED                   BLOCKED               MAPPED
  IDLE                      —                     NOT_YET_MAPPED
  ENTRY                     —                     NOT_YET_MAPPED
  ACTIVE                    —                     NOT_YET_MAPPED
  EXIT                      —                     NOT_YET_MAPPED

  NOT_YET_MAPPED reasons:
  - IDLE: entryStateMetadata.ts L57 forbids IDLE in RuleBook §1
  - ENTRY/ACTIVE/EXIT: RuleBook §1 covers pre-entry only; post-entry lifecycle

D. RuleBook EntryState → FinalEntryStatus (reverse) — NOT IMPLEMENTED
---------------------------------------------------------------------

  RuleBook EntryState   FinalEntryStatus   Status
  -------------------   ----------------   ------
  READY                 ENTRY_VALID        Documented only (lossy reverse not exposed)
  WATCH                 —                  NOT_YET_MAPPED (broader than WAIT_ENTRY)
  LOCKED                —                  NOT_YET_MAPPED (no FinalEntryStatus value)
  BLOCKED               —                  NOT_YET_MAPPED (ambiguous: SCORE/GROUP/HARD)
