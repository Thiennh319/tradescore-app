PHẦN 2 — RUNTIME MODEL
================================================================================

interface ActionRuntimeContext {
  actionEngineResult: ActionEngineResult
  scanId?: string
}

interface ActionRuntimeResult {
  actionEngineResult    // passthrough
  runtimeActions
  actionCount
  halted
  message
  context
}

interface RuntimeAction {
  actionId
  actionType
  executionOrder
  status
  metadata              // fromState, toState, reason
}

enum RuntimeActionStatus {
  PENDING
  SKIPPED               // NO_ACTION type only
}

Không có RUNNING / SUCCESS / FAILED / RETRY / TIMEOUT.

PHẦN 3 — RUNTIME FLOW
================================================================================

  validateActionRuntimeContext()
        ↓
  buildRuntimeActions()
        ↓
  validateActionRuntimeResult()
        ↓
  return ActionRuntimeResult

buildActionRuntimeResult(context) — entry point.

Rules:
  • Mỗi EntryAction → đúng 1 RuntimeAction
  • executionOrder bắt đầu từ 1, tuần tự theo thứ tự actions
  • Không reorder / priority / scheduler / batching
  • NO_ACTION → status SKIPPED; còn lại → PENDING
