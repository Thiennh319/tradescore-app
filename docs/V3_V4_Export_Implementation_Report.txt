NHÓM 2 — L5 audit (3)
  l5_block_path          Derive từ hard_blocks + block_reasons + warnings:
                           CVD trong hard_blocks → HARD
                           'L5a CVD chưa đủ' trong block_reasons → SCORE
                           CVD phân kỳ / bull trap / bear trap → SOFT
                           else → NONE
  l5b_score              V4 only — layer id 52 (LAYER_L5B_ID), 4 decimal
  l5b_note               V4 only — layer 52 reason

NHÓM 3 — SL audit (3)
  sl_quality             plan.stopLoss.quality (TIGHT | NORMAL | WIDE)
  sl_atr_distance        plan.stopLoss.atrDistance (2 decimal)
  sl_profile_v4          V4 only — plan.slProfile | slMultiplierProfile |
                           slMultiplierResult.profile (hiện tại → '' — xem §5)

NHÓM 4 — Entry audit (2)
  entry_quality          plan.entryZone.quality
                           (PERFECT | GOOD | ACCEPTABLE | RISKY | MISS)
  rr_after_structure     plan.primaryRR (4 decimal)

NHÓM 5 — Plan lifecycle (2)
  plan_expiry_tier       plan.expiryTier (HIGH | MEDIUM | LOW)
  structure_lookback_config  Inline ADX map (không import structureSL):
                           adxAvg >= 35 → 40; >= 25 → 30; else 20
                           Không có adxData → '20'

NHÓM 6 — P0 audit (4 cột static + 1 dynamic)

                         v4 + l6Detail.isFallback true → V4_LEGACY
